Setup guide

Connect your workspace to ChatGPT in five steps.

1. Create a tunnel

Open OpenAI Platform tunnel settings ↗, create a tunnel, and select your organization and ChatGPT workspace. Save the tunnel ID.

2. Create a runtime API key

Open API keys ↗ and create a runtime key with Tunnels Read + Use permissions. Select restricted permissions where available and keep the key private.

3. Start the connection

Enter your tunnel ID, runtime API key, and workspace directory above. Start with a test folder: the server can read and overwrite its files. Select Start connection and keep this app running.

4. Add the connection in ChatGPT

In ChatGPT Plugins, select Add custom MCP server. Choose Tunnel, enter the same tunnel ID, and create the plugin. Keep the tunnel running while you create the plugin.

The screenshot shows OAuth selected as an example. This server does not provide OAuth; choose no authentication if available.

5. Test and troubleshoot

Open a new chat, select the plugin, and ask it to list the files in your workspace. Confirm that the response contains actual file names.

If the server is not initialized, make sure only one tunnel client is using this tunnel, restart the connection, and try a new chat. Verify that the plugin uses the same tunnel ID and ChatGPT workspace. A running client alone does not confirm the connection is ready.
